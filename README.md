# Food Storage

Android-приложение для учёта продуктов, мест хранения и сроков годности.

## О проекте

Food Storage помогает отслеживать продукты, хранящиеся дома, и контролировать сроки их годности. Пользователь может добавлять продукты, указывать место хранения, просматривать список, фильтровать продукты и удалять их.

> Проект находится в разработке.

## Реализованный функционал

* Добавление продуктов с указанием названия, количества, срока годности и места хранения.
* Валидация данных при добавлении продукта.
* Локальное хранение данных с использованием Room.
* Автоматическое объединение одинаковых продуктов согласно бизнес-логике приложения.
* Отображение списка продуктов.
* Подсчёт общего количества и просроченных продуктов.
* Фильтрация продуктов по месту хранения: «Все», «Холодильник», «Полка».
* Поиск продуктов по названию.
* Удаление продукта свайпом.
* Обработка состояний загрузки, пустого списка, отсутствия результатов поиска/фильтрации и ошибок.
* Уведомление об успешном сохранении продукта.

## Архитектура

Проект построен с использованием Clean Architecture и разделён на слои:

* **Presentation** — Compose UI, ViewModel и управление UI-состояниями.
* **Domain** — бизнес-логика, UseCase, модели и интерфейсы Repository.
* **Data** — Room, DAO, Entity, Mapper и реализация Repository.

Основной поток данных:

```text
UI → ViewModel → UseCase → Repository → Room
```

Результат изменений в базе данных передаётся обратно через Flow:

```text
Room → Repository → UseCase → ViewModel → StateFlow → UI
```

## Управление состоянием

Основное состояние экрана хранится во `ViewModel` и передаётся в UI через `StateFlow`.

Для одноразовых событий используется `SharedFlow`, например:

* успешное сохранение продукта;
* показ `Toast`;
* возврат на предыдущий экран.

Для списка продуктов используется единый источник данных:

```text
allProducts
    ↓
selectedFilter
    ↓
searchQuery
    ↓
итоговый список
    ↓
UI state
```
## Планируемый функционал

* Редактирование продуктов.
* Уведомления об истечении срока годности с использованием WorkManager.
* Распознавание данных с помощью камеры для быстрого заполнения информации о продукте.
